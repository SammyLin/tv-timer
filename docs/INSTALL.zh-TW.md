# 把「看電視計時」裝到電視(給不熟電腦的人)

跟著做大約 **15 分鐘**。不用懂程式,只要會按遙控器、會複製貼上就可以。

**你需要:**
- 一台 Google TV / Android TV(例如 Sony BRAVIA)
- 一台 Mac 或 Windows 電腦
- 電視和電腦連**同一個網路**(同一台路由器的 Wi-Fi 或網路線都可以)

整個流程分兩段:**電視上打開兩個開關 → 電腦貼一行指令**。電腦會自己在家裡網路上找到電視。

---

## 第一段:在電視上打開兩個開關

這兩個開關是讓電腦可以把 App 裝到電視上。用遙控器操作。

### 1. 打開「開發人員選項」

1. 進到 **設定**(畫面右上角的齒輪)
2. 選 **系統** → **關於**
3. 往下找到 **Android TV 作業系統版本**(有些電視叫「版本號碼」或「Build」)
4. 對著它**連按 7 下**遙控器的確認鍵
5. 畫面下方出現「**您現在已經是開發人員了**」就成功了

> 按到一半會出現「再按 N 次就會成為開發人員」,繼續按就對了。

### 2. 打開「USB 偵錯」

1. 回到 **設定** → **系統**
2. 會多出一個 **開發人員選項**,點進去
3. 找到 **USB 偵錯**,把它**打開**
4. 跳出確認視窗就按 **確定**

> 雖然叫「USB」偵錯,但電腦是透過網路連的,不用接線。

---

## 第二段:在電腦上貼一行指令

### 🍎 Mac

1. 按鍵盤 **⌘ Command + 空白鍵**,打「**終端機**」,按 Enter 打開
2. 把下面這一行**整行複製**,貼到終端機裡(⌘ Command + V),按 **Enter**:

   ```
   curl -fsSL https://raw.githubusercontent.com/SammyLin/tv-timer/main/install/mac.sh | bash
   ```

### 🪟 Windows

1. 在畫面左下角的 **開始按鈕上按右鍵**,選「**終端機**」或「**Windows PowerShell**」
2. 把下面這一行**整行複製**,在視窗裡**按右鍵**就會貼上,再按 **Enter**:

   ```
   irm https://raw.githubusercontent.com/SammyLin/tv-timer/main/install/windows.ps1 | iex
   ```

3. 如果跳出「Windows 安全性警訊 / 防火牆」問要不要允許 **adb**,按 **允許**

### 接下來照畫面做

1. 它會問「**要做什麼?**」→ 第一次安裝直接按 **Enter**(就是「1 安裝或更新」)
2. 它會自己在家裡網路上找電視:
   - 顯示「**找到一台:192.168.x.x**」→ 直接按 **Enter**
   - 找到好幾台 → 輸入編號
   - 沒找到 → 照下面「[查電視的 IP](#查電視的-ip-位址)」查到後打上去
3. **看電視**:會跳出「**要允許 USB 偵錯嗎?**」
   → 勾選「**一律允許這部電腦**」,再按「**允許**」
4. 等它跑完,看到「🎉 安裝完成」就好了

打錯也沒關係,它會告訴你哪裡不對,按 Enter 就能重來;想放棄輸入 `q`。

### 查電視的 IP 位址

只有電腦**沒自動找到電視**時才需要。IP 位址就是電視在家裡網路上的「門牌號碼」,長得像 `192.168.1.23`。

1. 電視 **設定** → **網路和網際網路**
2. 點你**目前連著的網路**(Wi-Fi 名稱,或「乙太網路」)
3. 找到 **IP 位址**,把那串數字打進電腦

---

## 裝好之後

電視會出現「誰要看電視?」的畫面,**最下面一行**寫著 **爸媽手機網址**(像 `http://192.168.1.23:8765/`)和 **初始爸媽密碼**。**先拍照記下來。**

1. 手機連家裡的 Wi-Fi,用瀏覽器打開那個網址
2. 輸入初始密碼,到「設定」**改成你自己的密碼**,順便把小孩的名字改好(改掉之後電視上那行就不會再顯示)
3. 想要像 App 一樣從手機主畫面打開:
   - iPhone:Safari 下面的「分享」→「加入主畫面」
   - Android:Chrome 右上角「⋮」→「加到主畫面」

之後電視一打開就會先顯示選人、選時間的畫面,時間到會播一段音樂並鎖起來。

---

## 忘記密碼、壞掉了怎麼辦

貼**同一行指令**,選單選別的:

| 狀況 | 選 | 會怎樣 |
|---|---|---|
| **忘記爸媽密碼**,或密碼錯太多次被鎖住 | **2** | 換一組新密碼,直接顯示在電腦上(電視鎖定畫面最下面也有)。小孩名字和紀錄**都保留** |
| **App 壞掉**、電視一直被鎖住、或不想用了 | **3** | 從電視**強制移除**,電視馬上解鎖。所有設定會清掉 |
| 想重裝 | **3** 再 **1** | 先移除再裝一次,等於全部重來 |

> 這兩個都需要電視的「USB 偵錯」開著。為了不讓小孩自己解鎖,電視上沒有不用電腦就能重設密碼的方法。

## 常見問題

**電腦說「這個 IP 沒有回應」**
- IP 有沒有打錯?回電視「設定 → 網路和網際網路」再看一次
- 電視和電腦是不是連同一個網路?(有些路由器有「訪客網路」,那個不算)

**電腦說「有裝置,但它沒有開 USB 偵錯」**
- 回第一段把「USB 偵錯」打開。電視重開機後有時會自己關掉,再開一次就好

**電腦說「這台看起來不是電視」**
- 你可能打到別的裝置(例如手機、電視盒)的 IP。確認是電視的 IP 再試;真的要裝在 Android 電視盒上,輸入 `y` 繼續

**電視上沒有跳出「允許 USB 偵錯」**
- 如果電視正顯示「看電視計時」的鎖定畫面,那個視窗可能被蓋住了。先用爸媽手機頁按「改成不限制」(或在電視上選人開始看)讓鎖定畫面消失,再貼一次指令

**要怎麼更新到新版?**
- 用**同一台電腦**,再貼一次同一行指令就好,設定都會保留

**它說「電視上已經有一個看電視計時,沒辦法直接更新」**
- 代表電視上的舊版是用別的方式裝的。輸入 `y` 會刪掉舊的、裝新的,但舊的設定(密碼、名字、看了多久)會清掉

**不用電腦也能移除嗎?**
- 可以,但要先解鎖:用爸媽手機頁按「改成不限制」,再到電視「設定 → 應用程式 → 看電視計時 → 解除安裝」。手機頁也進不去的話,就用上面的「選 3」

**這個指令安全嗎?會裝什麼?**
- 只會下載兩樣東西:Google 官方的 Android 工具(adb),和這個專案在 GitHub 上的 App
- 檔案放在 Mac 的 `~/.tv-timer-installer`、Windows 的 `%LOCALAPPDATA%\tv-timer-installer`,裝完不需要可以整個刪掉
- 程式內容都是公開的:[mac.sh](../install/mac.sh)、[windows.ps1](../install/windows.ps1)

**小建議**
- 在路由器設定裡幫電視「**保留固定 IP**」,這樣爸媽手機網址就不會哪天突然變掉
